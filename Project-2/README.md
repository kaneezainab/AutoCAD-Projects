# Project 2 — 3D Mechanical Bracket

## 📌 Project Overview

This project presents the design and development of a three-dimensional mechanical bracket created using **Autodesk AutoCAD**.

The component was modeled using 3D solid modeling techniques and includes a reinforced base plate, vertical support wall, structural rib, cylindrical boss, mounting holes, and a central opening. The final model was accurately dimensioned and presented in an isometric view for clear engineering visualization.

---

## 🎯 Objectives

The main objectives of this project were to:

- Develop a complete 3D mechanical component using Autodesk AutoCAD.
- Apply accurate geometric dimensions to the design.
- Use 3D solid modeling techniques to construct the bracket.
- Apply Boolean operations such as `UNION` and `SUBTRACT`.
- Create mounting holes and a central cylindrical opening.
- Apply professional technical dimensioning.
- Present the final model clearly for engineering documentation.

## ⚙️ Design Features

The completed mechanical bracket consists of the following major features:

### 🔹 Base Plate
- Length: **120 mm**
- Width: **80 mm**
- Thickness: **10 mm**

### 🔹 Vertical Support Wall
- Height: **60 mm**
- Provides structural support to the bracket assembly.

### 🔹 Reinforcing Rib
- Included to improve structural rigidity and stability.
- Provides additional support between the base and vertical structure.

### 🔹 Cylindrical Boss
- Outer diameter: **Ø30 mm**
- Provides a central mounting and support feature.

### 🔹 Central Opening
- Diameter: **Ø16 mm**
- Created using a Boolean subtraction operation.

### 🔹 Mounting Holes
- Quantity: **4**
- Diameter: **Ø8 mm each**
- Positioned on the base plate for mounting purposes.

---

## 🧰 Modeling Methodology

The mechanical bracket was developed through the following workflow:

1. A rectangular solid was created to form the base plate.
2. A vertical support wall was modeled and positioned on the base.
3. A reinforcing rib was added to improve structural stability.
4. A cylindrical boss was created at the center of the base plate.
5. The main solid components were combined using the `UNION` command.
6. Four cylindrical cutting tools were created for the mounting holes.
7. A central cylindrical cutting tool was created for the boss opening.
8. The required openings were produced using the `SUBTRACT` command.
9. The final geometry was reviewed using a 3D isometric view.
10. Technical dimensions and annotations were added using AutoCAD dimensioning tools.
