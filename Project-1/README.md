# Project 1 – AutoCAD Design

## Overview

This project was completed as part of my internship training and focuses on the development of technical drawings using AutoCAD. The project demonstrates the application of computer-aided design (CAD) techniques to create accurate, organized, and professional engineering drawings.

## Objectives

- To develop practical skills in AutoCAD.
- To create accurate technical drawings using CAD tools.
- To apply proper drawing standards and design principles.
- To improve proficiency in drafting and digital design.

## Features
- 2 Bedrooms
- Living Room
- Dining Room
- Kitchen
- Bathrooms
- Entrance/Foyer
- Dimensions and annotations
- Title block

## Software Used
